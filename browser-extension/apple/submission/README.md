# Apple submission preparation  -  not an upload

This kit is prepared for publisher review. It includes EN/IT metadata and descriptions, TestFlight testing copy, review notes, code-based privacy-answer proposals, signing/export instructions, screenshot requirements, a synthetic notice and a QA matrix. It does not include passwords, keys, signing profiles, a selected team or an App Store Connect record.

The current public Safari store state remains **unavailable**. An unsigned build, container startup, API-shim test or native-handler unit test is not a functioning App Store extension. Inspect the dated audit receipt before making any availability claim.

The metadata fields meet the prepared length limits (name/subtitle30, promotional text170, keywords100 bytes, description4000). The draft intentionally states the remaining qualification. Once external testing is complete, update the metadata to the true reviewed release state; do not carry “not uploaded yet” copy into an approved production listing.

Publisher-only missing inputs: legal seller/account role and active membership; team and bundle ownership; distribution signing/provisioning; review-contact details; confirmed server/log/partner retention for App Privacy; final age/content and export-compliance answers; functional Safari/device evidence; accepted screenshots; actual Apple build/submission/review receipts.

No paid resources, memberships, account registrations or Apple uploads were performed.
