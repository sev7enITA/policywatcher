# Native dashboard user guide

PolicyWatcher’s native dashboard is an evidence navigation surface. It helps readers locate, filter, compare, and share public policy evidence; its visual scores are not legal advice, compliance certifications, or company-performance ratings.

## 1. Choose a workspace

Open **Dashboard setup** and choose a session goal and evidence depth. The workspace rearranges approved modules without weakening source or public-evidence gates.

## 2. Configure and share a view

Set the relevant industry, risk, region, audience, time, search, sort, language, and workspace controls, then select **Copy view**. The canonical URL records committed public view state. It excludes personal or private evidence and consent state.

Browser Back and Forward restore valid committed views. Unknown, stale, or invalid URL values fail closed instead of silently selecting a different filter.

## 3. Check source status

Read source warnings before interpreting a summary, score, or comparison. A suspended, unavailable, seeded, partial, or review-needed record is not presented as verified public evidence.

## 4. Inspect policy evidence

Open **View analysis** from a company or change record. Check the retrieval status, source URL, baseline, observed changes, provenance, and stated limitations before using a generated summary.

## 5. Select regional context

In the region heatmap, select a cell to commit its region and audience together. Missing cells remain **Not assessed**; they are not treated as low risk. Use the adjacent exact-value table for precise values and keyboard-accessible inspection.

## 6. Inspect a benchmark KPI

Select a radar dimension to open the KPI inspector. It shows the original assessment and its normalized ordinal value for each compared record. Missing values and ties remain explicit, and unassessed values cannot create a win.

Normalized values make differently worded assessments comparable. They do not measure compliance, legal readiness, implementation quality, or business performance. Use the exact-value table whenever the chart alone is insufficient.

## 7. Use the evidence routes

Use the policy-change timeline for operational change records, the Feature Atlas for release KPI/KRI impact, Observatory for monitored external signals, and Methodology for definitions and boundaries.

## 8. Read on mobile

The optional On-the-Go workspace condenses the page while keeping source notices and essential evidence controls visible. The choice is local to the browser and can be changed through **Change view**.

## 9. Treat outputs as decision support

PolicyWatcher reports the public evidence it can verify and names the evidence it cannot assess. Confirm material decisions against the linked primary source and qualified legal or compliance advice.
