# PolicyWatcher Beta 21 publication guide

## Publication-ready files

- `PolicyWatcher-Systems-Paper-Beta21-2026-07-30.pdf`: 20-page academic PDF.
- `PolicyWatcher-Systems-Paper-Beta21-2026-07-30.docx`: editable, branded
  publication edition.
- `policywatcher-arxiv.tex`: self-contained TeX source with embedded references.
- `data/operational-snapshot-2026-07-30.json`: dated public-API evidence artifact.
- `PAPER-AUDIT.md`: claim boundaries, validation and future-study requirements.

## Recommended metadata

- **Title:** PolicyWatcher: An Evidence-Preserving Pipeline for Monitoring
  Terms-of-Service and Privacy-Policy Changes on Consumer Technology Platforms
- **Author:** Fabrizio Degni
- **Primary arXiv category:** `cs.CY`
- **Possible cross-lists:** `cs.SE`, `cs.CR`
- **Suggested comments:** "20 pages. Platform and reproducibility material at
  https://policywatcher.online."
- **License:** select the license intentionally in the publication form. CC BY
  4.0 supports broad reuse; arXiv's non-exclusive license is another option.

## Required checks before submission

1. Confirm author name, affiliation and contact email in the submission form.
2. Keep the manuscript date fixed at 30 July 2026 unless the snapshot and paper
   are revised together.
3. Do not convert operational counts into legal, semantic-accuracy, compliance,
   adoption or comparative-performance claims.
4. Upload the minimal source package generated by
   `bash scripts/package-arxiv-source.sh`; do not upload repository directories,
   environment files, build logs, the DOCX or the local PDF as TeX sources.
5. Inspect the PDF generated by the publication platform before confirming.

## Minimal arXiv package

Run from the repository root:

```sh
bash scripts/package-arxiv-source.sh
```

The command compiles the TeX source from an isolated temporary directory and
creates:

```text
output/arxiv/policywatcher-arxiv-beta21-source.zip
```

The ZIP contains only:

```text
policywatcher-arxiv.tex
data/operational-snapshot-2026-07-30.json
data/README.md
```

The JSON and README are ancillary evidence material; the TeX file compiles
without them.

## Communication boundary

Describe the work as an independent civic-technology systems project. Do not
describe it as approved, certified, audited or endorsed by the European
Commission, and do not state that it assesses conformity with the AI Act.
