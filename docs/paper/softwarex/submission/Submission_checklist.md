# SoftwareX submission checklist

Prepared against the SoftwareX Guide for Authors and Original Software
Publication template consulted on 23 July 2026.

## Manuscript

- [x] Official Elsevier OSP LaTeX structure (`elsarticle`).
- [x] Five required sections in the prescribed order.
- [x] Mandatory C1–C8 code metadata table.
- [x] Abstract below 250 words (153 words by tokenized count).
- [x] Six keywords (journal permits one to seven).
- [x] Main manuscript below 4,000 words (approximately 2,400 including
  abstract, running text, captions, and declarations; references excluded).
- [x] Two figures (journal maximum: six), both original vector graphics.
- [x] Full author affiliation, postal address, corresponding email, and URL.
- [x] Data availability, CRediT, funding, competing-interest, generative-AI,
  and acknowledgement statements included before the references.
- [x] PDF compiled successfully and visually inspected page by page.

## Separate upload files

- [x] Editable highlights: four bullets, each at most 85 characters.
- [x] Cover letter in editable DOCX format.
- [x] Competing-interest declaration in editable DOCX format.
- [x] Optional graphical abstract in vector PDF format.
- [x] Supplementary JSON data, collection script, and interpretation README.
- [x] Complete LaTeX source ZIP with source, figures, and supplementary data.

## Repository

- [x] Public GitHub repository identified in manuscript metadata.
- [x] Source code is under `src/`.
- [x] Root `README.md` contains installation and use documentation.
- [x] Root `LICENSE.txt` provides the OSI-approved MIT License.
- [x] Documentation and research content retain a separate CC BY 4.0 license.
- [x] The MIT license, updated README, SoftwareX manuscript source, and
  supplementary snapshot are committed in the immutable code snapshot cited in
  C2/C7 and published in the public GitHub repository.

## Editorial-system checks

- [ ] Confirm author name, affiliation, email, and corresponding-author flag.
- [ ] Select article type “Original Software Publication.”
- [ ] Upload the manuscript PDF and LaTeX-source ZIP as the main manuscript
  source, plus highlights, declaration, graphical abstract, and supplement in
  their matching file categories.
- [ ] Paste the funding answer (“No specific funding”) and data statement when
  requested by the submission form.
- [ ] Review the generated proof, especially metadata-table URLs and figures.
- [ ] Confirm the manuscript is not under consideration by another journal.
