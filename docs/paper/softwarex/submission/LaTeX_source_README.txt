PolicyWatcher — SoftwareX LaTeX source

Compile policywatcher-softwarex.tex with a current LaTeX distribution that
provides elsarticle.cls, booktabs, graphicx, hyperref, tabularx, xcolor, and
array. The figure PDFs are original vector graphics generated by
build_figures.py. Supplementary Data contains the dated JSON snapshot used in
Table 2, the read-only collection script, and interpretation notes.

Suggested command:
  tectonic policywatcher-softwarex.tex

The software source repository is:
  https://github.com/sev7enITA/policywatcher
