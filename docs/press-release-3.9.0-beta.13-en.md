## Full news release

### PolicyWatcher launches Pulse, an editorial layer for distributing verifiable evidence about public policy changes

Version 3.9.0 Beta 13 adds deterministic Story Packs, multiformat social cards, citable embeds and structured Data Room metadata.

29 July 2026 - PolicyWatcher has released version 3.9.0 Beta 13, named Editorial Pulse and Distribution. The release adds tools that help journalists, analysts and researchers inspect and reuse information already supported by the platform's public evidence.

The new `/pulse` area contains a limited registry of reviewed story leads. Each record shows an as-of date, facts, proof links, an interpretation boundary and a suggested citation. The system does not automatically promote database rankings or AI-generated content into public stories.

Each lead includes:

- a deterministic, versioned Story Pack ZIP with a manifest, pitch, facts, sources and citation;
- social cards for Open Graph, square, portrait feed and story formats;
- an embeddable visual with visible source, date, boundary and citation;
- `NewsArticle` metadata and a story-specific Open Graph image;
- direct links to the Claim Registry, Data Room and release records.

The Data Room now publishes `Dataset` and `DataDownload` metadata that describe its dated snapshot and available distributions. Release pages and the Data Room also use dedicated Open Graph images.

PolicyWatcher records aggregate events for story views, downloads, citation copies, embed-code copies and launch-kit actions. Persistent records contain only the event type, an allowlisted target, locale and server timestamp. They do not contain persistent visitor identifiers, IP addresses, user agents, referrers, query strings or raw user content. Totals represent events, not unique people, confirmed readership or conversions.

"Pulse is intended to shorten the path between a publishable statement and the evidence that supports it. Each asset keeps its date, source and limits visible so that editors can inspect the context before publication," said Fabrizio Degni, creator of PolicyWatcher.

### Updates delivered during the last two weeks

In addition to Pulse, the recent release cycle introduced:

- an Evidence Newsroom with a Claim Registry, Data Room, English and Italian press packages and correction records;
- a separate source-continuity timeline that does not present retrieval states as provider policy changes;
- a verified link to the published Chrome Web Store listing, while no official Edge listing has yet been verified and Safari remains unavailable;
- a public developer directory and read-only APIs with explicit data and rate boundaries;
- local `.eml` intake in browser memory, without mailbox connection, raw-message upload or attachment opening;
- a Microsoft Entra-protected Enterprise API v2 and Power Platform package for controlled pilots, not general availability;
- a protected database-readiness console that distinguishes ready, degraded and unavailable states.
