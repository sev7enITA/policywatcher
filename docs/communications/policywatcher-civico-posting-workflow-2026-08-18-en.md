## Post production workflow

1. **Choose one job per post.** Do not combine launch, country case study and contribution request in the same caption.
2. **Attach the image natively.** Put the public URL in the copy and add complete alt text.
3. **Use no more than three motivated mentions.** A mention must correspond to a documented public source or to the specific country case.
4. **State the trust boundary.** Inclusion is not partnership or endorsement; coverage is not exhaustive.
5. **Answer with a precise view.** When somebody asks about a country or topic, reply with a shareable filtered URL rather than a generic homepage link.
6. **Keep measures separate.** Track directory visits, source opens, copied views and user-initiated submission/correction drafts separately from impressions.

## Function-to-content map

| Product function | Best content format | Demonstration |
| --- | --- | --- |
| Region / country context | Country follow-up | Change the global context and show the national, regional and global mix |
| Eight protection filters | Technical carousel or crop | Select one protection type and show the result count |
| Search | Short screen capture | Search a domain term such as privacy or financial services |
| Shareable view | Comment reply | Copy a filtered URL and open it in a fresh session |
| Verification source | Evidence post | Open the source from one listing and explain what it does and does not verify |
| Submit a listing | Contribution post | Select “I represent this organization”, supply both HTTPS sources and prepare the email draft |
| Report a correction | Trust post | Open the card action and show the prefilled listing ID and current sources |
| Policy radar and local review | Workflow post | Move from an eligible change to browser-local review state and Markdown digest |

## Reusable closing lines

- “Which country or protection area should we deepen next?”
- “Represent an eligible organization? Submit your listing with two public HTTPS sources.”
- “Found an outdated record? Use Report a correction from the listing card.”
- “Inspect the source, keep the review human.”

## Measurement boundary

Email drafts are a client-side handoff, not confirmed submissions. A copied view is an interaction, not adoption. Publication and corrections remain manual editorial decisions.
