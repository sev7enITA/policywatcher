## Claim boundaries

Product 5.5 is the public stable service. Engine 6 is a private administrative Preview with separate data within the current hosting account. Its automatic public changes and notifications remain disabled. Compare runs two extractors on the same captured response. Source completeness, observations across days, and real-scale operation remain qualification tracks. 500 policies per day is a target, not an achieved production qualification. Test totals are deliberately not combined into an accuracy claim.
