# PolicyWatcher v3.6.3 Interactive Infographic

Standalone animated infographic for live demo, recorded video, LinkedIn capture, and internal stakeholder presentation.

## View

Open `index.html` in a modern browser. No build step, server, or external dependency is required.

## Files

- `index.html` - page structure and release content
- `styles.css` - responsive visual system, motion, and presentation mode styling
- `script.js` - feature constellation, auto-cycle, pipeline highlight, and workspace simulator
- `assets/logo-mark.png` - copied local PolicyWatcher mark

## Controls

- `Presentation Mode` raises contrast and hides microcopy.
- `Cycle features` auto-advances through the feature constellation.
- Job and depth controls update the registered evidence-module composer.
- The pipeline demonstrates the five persisted Bulk Source Onboarding stages and its private-baseline publication boundary.
