What it does
Turns the first screen into a job and depth selector for policy intelligence work.
Why it matters
Different audiences can begin with their task instead of decoding a static dashboard.
Changed in v3.6.3

Data-quality boundary
The workspace changes the view logic; it does not rewrite source records or bypass review.

Animated pipeline

Bulk source onboarding with an explicit publication decision.

Each imported candidate is persisted through five stages. The first baseline remains private; QA approval still requires a separate publish, hold, or reject decision.

  1. 01 Proposed source CSV/TSV candidate, validated and private
  2. 02 Official-source review Approve or reject source fit
  3. 03 First baseline Captured as private evidence
  4. 04 QA gate Evidence checks must pass
  5. 05 Publication decision Explicit publish, hold, or reject
