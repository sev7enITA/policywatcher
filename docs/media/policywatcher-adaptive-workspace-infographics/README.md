# PolicyWatcher Adaptive Workspace Infographics

Animated HTML mini-deck for the PolicyWatcher 3.6.3 Objective-based Dashboard Composer.

## Files

- `index.html` - three animated infographic scenes.
- `styles.css` - visual system, layout and animations.
- `script.js` - slide navigation, auto-play, keyboard controls.

## Scenes

1. **Start with the objective. Preview the evidence stack.**
   Shows the first-use guide composing registered dashboard modules before explicit apply.

2. **Four intents. Three evidence depths. One source-quality rule.**
   Shows Citizen, GRC / Legal, Research, Builder plus Snapshot, Operational, Forensic, with Source QA pinned.

3. **The latest build turns the site into a guided evidence workspace.**
   Maps the evidence surfaces and the protected Bulk Intake admin boundary.

## Controls

- Click `Logic`, `Categories`, `Build Map` to jump between scenes.
- Use arrow keys or PageUp/PageDown to navigate.
- Press Space or click `Auto-play` to pause/resume automatic cycling.

## Export

Open `index.html` in a browser and record the viewport at 16:9.
Recommended capture size: `1920x1080`.

For a short LinkedIn-ready clip, record 25-30 seconds and export as MP4.
For GIF conversion, keep the final GIF under the platform size limit and reduce FPS to 12-18.
