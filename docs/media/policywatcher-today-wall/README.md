# PolicyWatcher Today Wall

Single-wall infographic for presenting what PolicyWatcher is today and how the
platform reached the 3.5.1 Confidence / Audit Operations track.

## Files

- `index.html` - browser wrapper with fullscreen, print/PDF and download controls.
- `cinematic-deck.html` - animated presentation deck using the numbered PNG slide set.
- `policywatcher-today-wall.svg` - source vector wall, scalable.
- `png/0.png` through `png/5.png` - progressive presentation slides. Treat
  embedded dataset figures as local inventory context, not public-confidence
  evidence.

## Release Inventory Numbers

The wall uses current local release inventory metrics, not public-confidence
dataset statements:

- 16 configured companies
- 50 configured policy records
- 103 policy snapshots
- 53 detected policy changes
- 318 regional impact rows
- 15 governance KPIs
- 55 tests passing
- 5 GitHub Actions workflows
- Dataset QA now blocks seeded/demo records until source evidence is refreshed

The wording intentionally avoids legal, compliance, or security certification
absolute wording. It presents PolicyWatcher as a public-policy evidence mapping and
confidence infrastructure.
