# PolicyWatcher v4.0.0-beta.5 - October 2026 (1 October 2026)

Document Scope and Comparable Evidence adds a shared multi-select document scope to dashboard analyses. Privacy, service terms, AI terms, DPA, acceptable use and community guidelines can be selected together, with missing or unassessed coverage explicit for every company.

The selection reaches evidence coverage, comparison, KPI matrix, timeline, assistant context, shared views and CSV. Scores are averaged within types, across types and then equally across eligible companies. Explicit-subset means and industry benchmarks require all requested types to be assessed. KPI coverage counts canonical assessed values over 15 times current public policies; it is an availability measure, not a confidence or accuracy claim.

Methodology (English/Italian and modal), Site Atlas, Feature Atlas, release impact, trust information and newsroom use the same boundaries. Historical releases and frozen media assets retain their dates and versions.

Includes the Beta 4 evidence-consistency repair and SMTP configuration support. Mail delivery is not confirmed without mailbox configuration and verification.

The release also updates Next.js, Nodemailer, sharp, undici and browser-mapping dependencies in response to the release audit. Exact locked versions and final audit results are recorded in the coherence report.

Status: source candidate. Deployment evidence is recorded separately after staging and production verification. No publication claim follows from this release note alone.

See `docs/document-scope-2026-10-01.md` and `docs/reports/release-coherence-2026-10-01/README.md` for verification and limitations.
