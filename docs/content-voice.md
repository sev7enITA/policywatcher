# PolicyWatcher content voice

PolicyWatcher uses functional interface language. Every visible string names a function, data set, state, action or boundary.

## Core rules

1. Give each string one role: page title, section title, description, state, action or boundary.
2. Use a noun label for page and section titles: `Updates`, `Saved items`, `API`, `Sources`, `Account sync`.
3. Use one factual sentence for descriptions. State the input, output or user action.
4. Reserve imperative verbs for buttons, links and step instructions. Do not use them as hero or section headlines.
5. Keep states compact: current value, timestamp and next available action when useful.
6. Do not use slogans, narrative framing, rhetorical questions or contrast formulas such as “X, not Y”, “X without Y”, “from X to Y” or “prima X, poi Y”.
7. Avoid commentary about calmness, trust, confidence, clarity or sophistication. Name the underlying control or evidence instead.
8. Put real legal, privacy and technical limits in clearly labelled boundary copy. Necessary negative wording belongs in errors, unavailable states, privacy guarantees, disclaimers and limitations.
9. Do not name pairing, synchronization, background work, push delivery or another capability unless the implemented interface provides it.

## Interface labels, actions and boundaries

Interface headings name the page, function or contained data.

- Heading: “Integrations” / “Integrazioni”.
- Section: “Data shared” / “Dati condivisi”.
- Description: “API consumers receive published evidence records.” / “I client API ricevono record di evidenze pubblicate.”
- Action: “Open API documentation” / “Apri la documentazione API”.

Boundary copy records a genuine limit and may use negative wording when accuracy requires it.

- Privacy: “Shared links include public identifiers only. Review status stays on this device.”
- Operational state: “The public feed is unavailable. Try again.”
- Legal scope: “AI-assisted screening is not legal advice.”
- Technical scope: “The feed updates while the app is in use.”

Do not soften or remove a material limitation to make the copy sound more positive. Label it, state it directly and place it next to the feature or evidence it qualifies.
