# Code of Conduct

## Our Standard

PolicyWatcher is a civic-tech project. Participation should be respectful,
specific, and evidence-oriented.

Expected behavior:

- Use welcoming and inclusive language.
- Focus criticism on code, data, documentation, or methodology.
- Respect different levels of expertise and availability.
- Disclose conflicts of interest when relevant to a contribution.
- Avoid overstating security, compliance, legal certainty, or data
  quality.

Unacceptable behavior:

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without consent.
- Public disclosure of unresolved security vulnerabilities.
- Submitting knowingly false statements, fabricated evidence, or misleading data.

## Enforcement

Issues can be reported to:

info@policywatcher.online

Security-sensitive issues should be sent to:

security@policywatcher.online

Project maintainers may remove comments, close issues, reject contributions, or
limit participation when behavior conflicts with this code of conduct.

## Attribution

This code of conduct is intentionally concise and adapted for the current
PolicyWatcher project governance model.
